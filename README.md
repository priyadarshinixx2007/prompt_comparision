# Prompt Comparison

## Overview

Prompt Comparison is a simple web application created to understand how different prompt styles can affect the responses generated by a Large Language Model (LLM).

The application allows the user to enter a topic or question and compare the responses generated using different prompt styles. This helps in understanding the importance of prompt design when working with LLMs.

## Objective

The main objective of this project is to understand:

* How prompts are given to an LLM
* How different prompt styles can change the response
* The importance of clear and specific instructions
* How an LLM can be integrated into a simple web application
* How Streamlit can be used to create an interactive interface

## Features

* Simple and easy-to-use web interface
* User can enter any topic or question
* Compares three different prompt styles
* Generates responses using an LLM
* Displays the responses separately for easy comparison
* Built using Python and Streamlit

## Prompt Types

The application uses three prompt styles:

### 1. Basic Prompt

The user's input is directly given to the language model without adding additional instructions.

### 2. Detailed Prompt

The prompt provides additional instructions to generate a more detailed response. It asks the model to include important points and examples.

### 3. Concise Prompt

The prompt asks the model to provide a short and clear response to the given topic.

By comparing these three approaches, the user can observe how changes in the prompt can influence the generated output.

## How to Run the Project

### 1. Clone the repository

Clone the repository to your local system and open the project folder in VS Code.

### 2. Create a virtual environment

```bash
python3 -m venv venv
```

Activate the environment:

```bash
source venv/bin/activate
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Set the API key

The application requires an OpenAI API key.

Set the API key as an environment variable instead of directly adding it to the Python files.

```bash
export OPENAI_API_KEY="your_api_key"
```

Do not upload or share the API key on GitHub.

### 5. Run the application

```bash
streamlit run app.py
```

The application will open in the browser using the local Streamlit URL.

## Working of the Project

The user first enters a topic or question in the application.

The input is then passed through three different prompt templates:

1. Basic prompt
2. Detailed prompt
3. Concise prompt

Each prompt is sent to the language model and the generated responses are displayed separately.

This makes it easier to compare the effect of prompt structure on the final output.
